# Streaming Notifier

Synchronisiert einen Twitch-Streamingplan als Kalenderbild in einen Discord-Channel
und postet Discord-Benachrichtigungen, wenn auf Twitch/YouTube/Kick ein Stream
startet oder ein neues YouTube-Video erscheint.

Alle Zugangsdaten liegen verschluesselt in den GitHub-Secrets dieses Repos
(Settings -> Secrets and variables -> Actions). Im Code selbst steht nichts Geheimes.
